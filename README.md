# Taller de Estructura de Datos Lineales

**Estudiante:** Juan Andres Checa Sol

## Descripción

Taller sobre el uso de arreglos unidimensionales, arreglos bidimensionales o
matrices y ArrayList en Java. Incluye ejercicios de generación de datos aleatorios,
procesamiento (búsqueda, ordenamiento, operaciones matemáticas) e impresión de
resultados, aplicando principios de Clean Code y programación orientada a objetos.

## Estructura del proyecto

```
src/
├── arreglos/    Ejercicios 1-5: arreglos unidimensionales
├── arraylist/   Ejercicios 6-10: ArrayList
└── matrices/    Ejercicios 11-15: arreglos bidimensionales (matrices)
```

## Instrucciones para ejecutar

1. Clonar el repositorio: `git clone https://github.com/andres-checa/Taller-Estructura-Datos`
2. Abrir el proyecto en NetBeans o VS Code
3. Compilar y ejecutar cada clase de forma individual desde la carpeta correspondiente:
   1. Ubicarse en la carpeta donde se clonó el repositorio
   2. Utilizar el siguiente comando: `java src/<carpeta>/<NombreArchivo>.java`
